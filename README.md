# FIFA 2026 世界盃賽程表

## 專案簡介
提供 2026 FIFA 世界盃足球賽相關賽程資訊。具使用者友善的介面，快速查詢各組小組賽程、即時比數，以及各國家隊的詳細賽程等功能。

## 主要功能
*   **淘汰賽**：新增淘汰賽對戰組合與比賽日期。
*   **小組賽程一覽**：顯示所有分組的比賽日期與結果。
*   **比數更新**：提供比賽的最新比賽結果。
*   **國家隊賽程查詢**：點擊特定國家隊，即可查看該隊伍的所有比賽賽程。
*   **即將進行的比賽**：方便瀏覽近期即將進行的賽事。
*   **響應式設計**：在桌機與行動裝置上皆提供良好的瀏覽體驗。

## 使用技術
*   **前端框架**：Vue 3 (搭配 Nuxt 3)
*   **狀態管理**：Pinia
*   **路由**：Vue Router
*   **樣式預處理器**：SCSS
*   **語言**：JavaScript、TypeScript
